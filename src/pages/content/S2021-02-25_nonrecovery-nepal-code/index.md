This repository contains the source code and some of the data to replicate key results from our article “A data-driven approach to rapidly estimate recovery potential to go beyond building damage after disasters,” published in Communications Earth & Environment in 2023 (find that article <Link doOpenInNewTab to="nonrecovery-nepal"> here </Link>).

The code, written in R, carries out automatic variable selection and builds a model to rapidly estimate the spatial distribution of post-earthquake non-recovery, using the 2015 Nepal earthquake as a case study. The prepared predictors of non-recovery are included in the repository. The surveyed reconstruction data used in the paper are proprietary to The Asia Foundation and are not included. The code and data are licensed for non-commercial use under CC BY-NC-SA.
